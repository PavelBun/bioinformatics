# Инструкция по развертыванию и установке фреймворка CWL (Common Workflow Language)

Для запуска описанных в работе CWL-пайплайнов мы используем эталонный интерпретатор `cwltool`. Он написан на Python и использует Docker-контейнеры для запуска биоинформатических утилит.

## Требования к системе

1. **Python** версии 3.8 или выше.
2. **Docker Desktop** (на Windows должен быть запущен и настроен для работы с WSL 2).
3. **Node.js** (требуется для выполнения JavaScript-выражений внутри некоторых CWL-файлов).

---

## Пошаговая установка

### 1. Создание виртуального окружения Python

Виртуальное окружение позволяет изолировать зависимости фреймворка от системного Python:

```bash
# Открываем консоль в корневой папке проекта (hw-3)
# Создаем виртуальное окружение с именем 'venv'
python -m venv venv
```

### 2. Активация виртуального окружения

В зависимости от используемой командной строки выполните соответствующую команду:

*   **В PowerShell:**
    ```powershell
    .\venv\Scripts\Activate.ps1
    ```
*   **В Git Bash / Linux / macOS:**
    ```bash
    source venv/Scripts/activate
    ```
*   **В классической командной строке (cmd):**
    ```cmd
    .\venv\Scripts\activate.bat
    ```

После активации в начале строки ввода появится префикс `(venv)`.

### 3. Установка cwltool

Установите `cwltool` с помощью пакетного менеджера `pip`:

```bash
pip install --upgrade pip
pip install cwltool
```

Убедитесь, что установка прошла успешно:
```bash
cwltool --version
```

---

## Запуск тестового конвейера "Hello World"

Для проверки правильности установки запустите простой тест:

```bash
cwltool cwl/hello_world.cwl cwl/hello_world_job.yml
```

---

## Запуск основного конвейера анализа данных

Для запуска основного конвейера вызова вариантов выполните следующую команду в активированном окружении:

```bash
cwltool --basedir . cwl/pipeline.cwl cwl/pipeline_job.yml
```

При этом `cwltool` автоматически скачает необходимые Docker-контейнеры из BioContainers, выполнит анализ и сохранит результаты.

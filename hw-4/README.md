## 📌 Описание проекта
Данный репозиторий содержит решение Домашнего задания №4 по клинической и функциональной аннотации 50 однонуклеотидных вариантов (SNV) человека из файла `student_16.vcf`.

Аннотация выполнена с использованием баз данных:
* **Ensembl VEP (Release 116):** функциональные последствия на транскрипты и белки, MANE Select, алгоритмы SIFT и PolyPhen-2.
* **NCBI ClinVar:** клиническая значимость, статусы ревью, ассоциированные заболевания.
* **gnomAD (v4 / v3.1.2):** популяционные частоты альтернативных аллелей в экзомах и геномах по глобальным когортам.

## 🔬 Разбор трех вариантов (Кратко)

1. **`chr22:24186268_C>T` (`rs115684319`, ген `SUSD2`):**
   * *Молекулярное последствие:* миссенс-замена `p.Arg499Cys` (MANE Select `NM_019601.4`).
   * *In silico:* SIFT (`deleterious`, 0.01), PolyPhen-2 (`possibly_damaging`, 0.767).
   * *gnomAD:* частота в популяции AFR достигает **4.45%** (`gnomADg` = 1.28%).
   * *ClinVar:* **Benign** (VCV000769156).
   * *Вывод:* критерий ACMG BA1/BS1 (частота > 1%) опровергает избыточно жесткие алгоритмические предсказания патогенности.

2. **`chr22:33304315_G>A` (`rs113253213`, ген `LARGE1`):**
   * *Молекулярное последствие:* синонимичная замена `p.Asn548=` (MANE Select `NM_133642.5`).
   * *gnomAD:* частота в популяции AFR — **0.55%** (`gnomADg` = 0.16%).
   * *ClinVar:* **Conflicting classifications of pathogenicity** (VCV000095167). Ряд лабораторий классифицирует как Benign/Likely Benign, одна лаборатория внесла как VUS при диагностике дистрогликанопатий A6/B6.
   * *Вывод:* синонимичный полиморфизм в клинически тяжелом гене, требующий реклассификации в доброкачественный статус на основе gnomAD.

3. **`chr22:31091696_C>T` (`rs11913728`, ген `SMTN`):**
   * *Молекулярное последствие:* миссенс-замена `p.Ala494Val` (MANE Select `NM_134269.3`).
   * *In silico:* SIFT (`deleterious`, 0.00), PolyPhen-2 (`benign`, 0.444).
   * *gnomAD:* частота в популяции AFR — **3.46%**, 1000 Genomes — **1.12%**.
   * *ClinVar:* **Отсутствует в ClinVar**.
   * *Вывод:* иллюстрирует смещение выборки ClinVar (ascertainment bias) — ген структурного белка гладких мышц не входит в стандартные панели скрининга редких менделевских синдромов.
